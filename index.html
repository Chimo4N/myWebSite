About

はじめまして、もんじです。都内の大学で経済学（災害経済学）を学びながら、サイバーセキュリティを独学しています。TryHackMeのCyber Security 101を修了し、自分で運営するWebサイトを診断ツールで検証して、見つかった問題を修正してきました。将来は脆弱性診断エンジニアとして、Webアプリだけでなく、OSやサーバーにも領域を広げたいと考えています。

未知のものが好きで、知らない土地を歩いたり、スマホなしで旅をしたり、古本屋で本を探したり、将棋を指したりしています。強みは知的好奇心で、興味を持ったらすぐ着手し、ゴールから逆算して課題を見つけ、合理的に解決するのが好きです。最近のマイブームは、ベーコンエッグのサンドイッチとコーヒーの朝ごはんです。

学び方や考え方については、こちらに詳しく書いています。

Mindset

セキュリティを学び始めたきっかけと、今の学び方

きっかけは些細なことでした。大学1年の秋、特講の授業で、元ITエンジニアの留学生と話す機会がありました。家に帰ってYouTubeで「ハッカー なりかた」と検索すると、TryHackMeを紹介している人がいて、そこから勉強を始めました。

高校からパソコンを使い、2台目は自作したので、基本的な構造やセッションまでは順調に進められました。途中から一気に難しくなり苦戦しましたが、資料を読んだり動画を見たりしながら進めました。TryHackMeを始めて1年以上になります。有料プランにしてからは、Cyber Security 101の修了まで約7か月かかりました。

先のコースもありましたが、TryHackMeの中で「フラグは目的地ではなく、基礎を理解するためのもの」という趣旨の説明を目にしました。それなら深く学び進めるより、今までの知識を振り返りながら新しいことを始めようと考えました。そこで、AIを使って作ったWebサイトの直したい点を自分で調べて修正したり、公開ツールやLinuxのコマンドで安全性を検証したりしています。

今はWebアプリケーションに対する簡単な診断しか行っていません。今後、脆弱性診断エンジニアとして働けるなら、OSやサーバーにも学習を広げたいです。

大学での学び：リスクを構造で捉える

大学では災害経済学を学び、災害リスクを決める3要素（Hazard / Vulnerability / Exposure）や、直接被害・間接被害の仕組みを学びました。これを応用して、過去の災害への対応をSWOT分析し、リスクに強い仕組みをプレゼンしました。

資料では、1つの課題に1つの解決策を示すのではなく、新しいアイデアそれぞれについて、強みと弱み、強みから広がる機会、弱みから生まれる脅威まで整理しました。

大切にしている2つの問い

ハーバード大学の教授が語っていた問いに触れて以来、人生を楽しむうえで2つの問いを軸にしています。人生を楽しむうえで、2つの問いを軸にしています。1つ目は「何のために生きているのか」、2つ目は「何のためなら喜んで命を捧げられるか」です。

1つ目について、楽しさは何かが変わったときに生まれると考えています。変化を楽しめること自体が大切で、その時期、その場所でしか経験できないことを楽しむのが、生きる理由になると思っています。年を重ねて考えが変わる可能性もあります。

2つ目の答えは、まだ模索中です。自分のために使いたい時間ではなく、誰かのために時間を使いたいと思ったときに見つかるのかもしれません。それを探すこと自体も、生きる理由の一つだと思っています。
